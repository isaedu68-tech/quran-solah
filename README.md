# Quran & Solah

App Android cá nhân: giờ Solah + nhắc, đọc Quran (Uthmani) + dịch tiếng Việt, học thuộc (Hifz) với giọng Al-Husary, hướng Qibla.

Mỗi lần đẩy mã lên `main`, GitHub Actions tải dữ liệu Quran, đóng gói APK, đăng lên Releases và gửi vào Telegram.
